# S Chat — Publish-Ready Starter

A production-oriented starter for an AI character chat Android app.

Included:
- Android project skeleton configured for AAB
- Dark neon S Chat UI
- 18+ age gate / non-explicit mature positioning
- Character-specific profiles
- AI backend integration scaffold
- Per-user daily usage limits
- Premium entitlement API scaffold
- WavePay server-side payment/webhook scaffold
- Privacy policy draft
- Play Store checklist

IMPORTANT:
This is not a guaranteed Google Play approval or live-payment package.
You must use your own Google Play developer account, signing key, privacy-policy URL,
AI provider credentials, and approved Wave merchant/API credentials.
